第一步：登录 GitHub，点击右上角 + → New repository，创建一个新的公开（Public）仓库，例如命名为 cello-score-library。

第二步：将以下文件上传至仓库根目录：

  • index.html（本页面）
  • score-img/ 文件夹（内含所有乐谱预览图）
  • score-pdf/ 文件夹（内含所有乐谱 PDF）

第三步：进入仓库 → Settings → 左侧 Pages。

第四步：在 Build and deployment → Source 中选择 Deploy from a branch，Branch 选 main，文件夹选 / (root)，点击 Save。

第五步：等待 1～3 分钟，Pages 页面会显示公开访问链接，格式为：
https://你的用户名.github.io/cello-score-library/

💡 提示：后续更新素材或代码后，重新 push 到 main 分支即可自动刷新线上版本。

一、新增曲目（修改 JS 数据数组）

打开 index.html，找到 const scores = [...] 数组，在末尾添加新对象：

{
  id: 59,                              // 唯一数字序号，递增即可
  title: "新歌名",
  key: "C大调",                         // 所属调式
  difficulty: "入门",                   // 入门 或 简单
  fingerTip: "一把位指法要点说明…",
  practiceTip: "弓法节奏练习建议…",
  scoreImg: "score-img/新歌名.png",     // 预览图相对路径
  downloadUrl: "score-pdf/新歌名.pdf",  // PDF 相对路径
  tags: ["C大调", "国风流行"]           // [调式标签, 曲风标签]
}

二、上传乐谱预览图片

将乐谱截图或扫描图保存为 PNG/JPG，放入 score-img/ 文件夹，文件名与 scoreImg 字段一致，例如 score-img/新歌名.png。

三、上传乐谱 PDF 文件

将制谱导出的 PDF 放入 score-pdf/ 文件夹，文件名与 downloadUrl 字段一致，例如 score-pdf/新歌名.pdf。

四、替换已有素材

直接用同名文件覆盖 score-img/ 或 score-pdf/ 中的旧文件即可，无需修改代码（前提是文件名不变）。若改名，需同步修改 JS 数组中对应的路径字段。

五、本地测试

双击 index.html 即可在浏览器离线打开测试。确认无误后 push 到 GitHub，Pages 自动更新。
